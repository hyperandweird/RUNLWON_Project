# RUNLWON
RUNLWON allows you to run Linux on Windows via QEMU. You can successfully install RUNLWON on your computer by following these steps:

- 1: Download the runlwon.zip file.
- 2: Unzip the extracted folder.
- 3: Go to the linux6-12 folder.
- 4: Run setup.exe (if it's not already installed).
- 5: Once the program window closes, go to the C:\linux6-12 folder on your computer.

That's it! Now you can start the sample Debian 12 by going to the Debian folder. You can also start using your chosen Linux distribution by opening the "linuxadd.exe" program in the C:\linux6-12 folder, adding the .qcow2 file of the Linux distribution you want to add, and following the necessary steps.
